# writing-drill · 写作片段练习

由本机 Ollama 模型驱动的写作练习插件：模型出题 → 你写一段 → 交 AI 评判 → 按专业建议改进 → 反复迭代，直到 AI 判定达到较高水准。所有内容只在本机处理，不上传云端。

## 用法

1. 在侧边栏打开「写作片段练习」面板。
2. （可选）在「主题类型」「写作体裁」输入框里限定方向，例如主题 `亲情`、体裁 `散文`；留空则由模型自由出题/判断。
3. 点「出题」，模型流式生成一道具体的练习题目。
4. 在「你的习作」框里写下你的片段，字数不限。
5. 点「交 AI 评判」，模型从立意、结构、语言、细节、体裁契合度等维度打分（0-10）并给出「亮点」「建议」「达标判断」。
6. 达到达标线（默认 8 分）即通过；未通过时按「建议」逐条改进，再交一次，直到达标。

## 配置

所有字段都可选，缺省值如下，可在 profile 的 `cordis.patch.yml` 中覆盖：

```yaml
config:
  baseUrl: http://127.0.0.1:11434   # 本地 Ollama 地址
  model: qwen3.8:27b-mlx            # 出题/评判用的模型
  passScore: 8.0                    # 达标线（0-10）
  temperature: 0.7
  numPredict: 1600
  numCtx: 16384
  timeoutMs: 600000
```

也可用环境变量 `DSH_OLLAMA_URL`、`DSH_WRITING_MODEL` 覆盖地址与模型。

## 架构

- `index.js`：宿主侧，注册 `/api/writing-drill/{health,prompt,grade}` 三条路由；`prompt` 与 `grade` 以 NDJSON 流式返回，面板可实时显示模型的 token。
- `client.js`：面板 UI，注入到侧边栏 `panellist` 与主区 `main`。
- `locale/{zh,en}.json`：面板元信息；运行时文案内联在 `client.js` 的字典里。
- `test/smoke.mjs`：钉死评判结论解析（分数提取、达标判断、夹紧、缺失）的契约。

## 评判结论解析

模型输出的评判是自由文本，宿主用 `parseVerdict` 抽取分数与达标判断：

- 分数支持 `8.5 / 10`、`分数：7 分`、`得分 9 分` 等写法，并夹紧到 0-10。
- 达标判断识别 `达标判断：是/否/通过/达标`（及英文 `yes/pass/true`）。
- 若模型未给出明确达标判断，则以分数是否达到 `passScore` 兜底判定。
